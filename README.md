# Exploratory Data Analysis (EDA) on Iris Dataset

## Overview
This project is part of my Data Science Internship Task at Hex Softwares.

The objective of this project is to perform Exploratory Data Analysis (EDA) on the famous Iris dataset using Python and visualization libraries.

The analysis helps understand:
- Data distributions
- Feature relationships
- Correlations
- Species comparisons
- Patterns within the dataset

---

## Dataset Information

The Iris dataset contains measurements of iris flowers from three different species:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

### Features Included
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

---

## Technologies & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Tasks Performed

### Data Exploration
- Loaded dataset
- Checked dataset shape and columns
- Viewed statistical summary
- Verified data types

### Data Cleaning
- Checked missing values
- Removed unnecessary columns

### Statistical Analysis
- Grouped species-wise averages
- Observed feature distributions

### Data Visualization
- Histograms
- Pairplots
- Boxplots
- Countplots
- Correlation Heatmap

---

## Key Insights

- The dataset contains no missing values.
- Iris-setosa is clearly distinguishable from the other species.
- Petal Length and Petal Width are highly correlated.
- Visualizations helped identify feature relationships and distributions effectively.
